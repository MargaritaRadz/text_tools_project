#text_tools

## Topic
**Certainty in the Language of Mental-Health Posts — Depression vs. Anxiety**

This script compares the language of posts labeled Depression, Anxiety, and Normal in the Kaggle Sentiment Analysis for Mental Health dataset. It counts absolutist words (e.g., always, never) and low-certainty expressions (e.g., maybe, might) and reports how often each appears per 1,000 words in each group.
